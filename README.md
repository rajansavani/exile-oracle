# exile-oracle

Ask questions about Path of Exile builds, mechanics, and patches. A RAG (retrieval-augmented generation) assistant backed by the PoE Wiki and official patch notes.

**Status:** in development.

## Stack

- **API:** FastAPI (Python)
- **Embeddings + LLM:** OpenAI
- **Vector store:** Pinecone
- **Container:** Docker
- **Deploy:** Google Cloud Run
- **CI:** GitHub Actions
